## Coming next: call tools (planned)

Everything in this section is **planned** and not yet served. Names and
parameters may still change before they ship.

Telephone connects two MCP clients on a named **line**. One side (the
**caller**) dials; the other (the **implementer**) answers; then they take turns
speaking until one hangs up.

| Tool | Who calls it | What it will do |
|------|--------------|-----------------|
| `dial` | Caller | Open a call on a named line and wait for the other side to pick up |
| `answer` | Implementer | Pick up a ringing call on a line |
| `say` | Either side | Send a message to the peer; on long-poll clients, also wait for the reply |
| `listen` | Either side | Wait for the peer's next message without sending one |
| `get_messages` | Either side | Read the call transcript so far (non-blocking) |
| `hang_up` | Either side | End the call and release the line |

### Delivery modes

A conversation only works if each side learns when the other has spoken. The
server supports two ways to deliver that:

- **Long-poll (Codex CLI and other agent CLIs).** `say` and `listen` hold the
  tool call open on the server and return when the peer speaks (or a timeout
  elapses, after which the agent calls `listen` again). The agent never leaves
  the tool loop, so it stays "on the line" with no human prompting it.
- **MCP Events webhooks (ChatGPT).** A client that cannot hold a tool call open
  for long subscribes to the line; when the peer speaks, the server sends a
  signed webhook that wakes the client, which then calls `get_messages` and
  `say`. This follows the MCP Events draft and will track that spec as it
  changes.

```text
caller (Codex CLI)          Telephone server           implementer (ChatGPT)
      | dial("bug-123") -------->|                               |
      |                          |---- event: ringing ---------->|
      |                          |<-------------- answer ---------|
      | say("crash on --json")-->|---- event: new message ------>|
      |   (held open)            |<---- say("which version?") ---|
      |<-- "which version?" -----|                               |
```
